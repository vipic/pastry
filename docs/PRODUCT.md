# Pastry 产品说明

本文档记录 Pastry 当前代码已经实现的产品行为，用于产品理解、验收和后续迭代对齐。不包含尚未落地的路线图。

## 产品定位

Pastry 是一个 macOS 26+ 剪贴板历史管理器。它常驻菜单栏，在后台监听系统剪贴板变化，将文本、链接、图片、文件、RTF、HTML 等内容保存为可搜索、可筛选、可收藏的历史卡片，并通过全屏半透明 overlay 面板快速找回和粘贴。

核心体验是：

1. 用户在任意应用中复制内容。
2. Pastry 识别内容格式、来源应用和时间，并保存到本地历史。
3. 用户通过全局快捷键或菜单栏打开面板。
4. 用户搜索、筛选、选择卡片，并粘贴、复制、拖拽、预览、打开或分享。

## 入口与主流程

### 菜单栏

Pastry 以 LSUIElement 菜单栏应用运行，不占用 Dock。菜单栏图标提供两个入口：

- 左键：打开或切换剪贴板面板。
- 右键菜单：打开剪贴板、检查更新、打开设置、新手引导、退出应用。

### 全局快捷键

默认快捷键是 `Command + Shift + V`。用户可以在设置中重新录制快捷键，修改后会立即重新注册全局热键。

快捷键触发后，Pastry 显示一个不激活前台应用的全屏透明 overlay。面板使用底部托盘布局，宽屏下横向展示卡片，窄屏下纵向展示卡片。

### 粘贴流程

点击已选中的单张卡片会触发粘贴。键盘确认或快捷粘贴会先将对应内容写回系统剪贴板，再模拟 `Command + V` 粘贴到原目标应用。

多选粘贴时，会将文本内容和文件路径合并为多行纯文本写回剪贴板；图片会被跳过。单选文件和图片仍保留原生文件 URL 或图片格式。

## 支持的剪贴板内容

Pastry 当前支持以下内容类型：

| 类型 | 采集与展示 |
|---|---|
| 文本 | 保存纯文本内容，卡片显示最多 7 行预览，数据库保留完整内容。 |
| 链接 | http/https 链接会被标记为 Link；多行链接会显示为多链接列表。 |
| RTF | 保存纯文本内容，同时保留原始 RTF 数据用于写回和预览。 |
| HTML | 保存纯文本内容，同时保留原始 HTML 数据；会尝试解析 HTML 中的有序图文段。 |
| 图片 | 保存图片缩略图和原图映射，卡片显示图片预览；可带截图文字注释。 |
| 文件 | 保存本地文件路径，支持单文件和多文件列表，卡片异步加载图标或图片缩略图。 |
| Handoff | 识别 Universal Clipboard 来源，并在卡片底部标记为来自其他设备。 |

读取优先级按更具体的类型优先：文件 URL、网页 URL、图片、HTML、RTF、文本。对于微信/QQ 的自定义富文本，Pastry 会尝试从 `TencentAttributeStringType` 中提取文本内容。

## 面板 UI

面板由半透明托盘和固定尺寸卡片组成。顶部工具栏包含搜索、筛选、All/Favorites 标签和设置入口；筛选按钮、All/Favorites 与筛选标签的选中态统一使用品牌暖棕加深色与白色图文。

### 卡片结构

每张卡片包含：

- 顶部类型栏：显示格式图标和类型文字，背景使用来源应用提取出的主题色。
- 应用图标：显示来源应用图标；Handoff 内容显示设备联动图标。
- 内容区：按类型渲染文本、链接、图片、文件、HTML 图文或多链接列表。
- 底部信息：显示相对时间、来源应用或 Handoff 标记；收藏项额外显示 pin 图标。

链接卡片在网络预览开启后会尝试加载标题、描述和缩略图。没有预览数据时，会用 URL host 和路径降级展示。

### 选择与键盘行为

面板支持：

- 单击选择卡片，再次点击已选卡片进行粘贴。
- `Command` 点击进行多选。
- `Shift` 点击或方向键扩展选择范围。
- 方向键移动当前选择。
- `Enter` 粘贴当前选择。
- `Command + 1...9` 快速粘贴前 9 张卡片。
- `Command + A` 全选当前可见卡片。
- `Delete` 删除选中卡片，并弹出确认。
- `Esc` 关闭面板。

按住 `Command` 时，前 9 张卡片右下角会显示数字角标。

### 搜索与筛选

搜索框可通过 `/`、`Command + F`、`Tab` 或工具栏按钮打开，支持对内容进行全文搜索；其他普通按键不会自动触发搜索。当前实现优先使用 SQLite FTS 搜索内容和链接标题，同时会将来源应用名称匹配的结果合并进来。

苹果智能默认关闭。用户在设置的“苹果智能”页开启总开关后，搜索框显示智能找回按钮，并使用 macOS Foundation Models 设备端模型，把“昨天从 Safari 复制的 SQLite 链接”等描述拆成精确关键词、语义主题和来源应用、内容类型、日期区间、收藏、备注、Handoff 等明确条件。常见相对日期由本机日历规则解析；其他日期表达由模型解析。搜索应用后再次点按按钮可查看识别出的主题、关键词和筛选条件。历史正文会在设备上分批生成中英文摘要与概念标签，并通过系统 `NaturalLanguage` 句向量建立本地语义索引；搜索合并关键词、概念扩展与向量候选，使用 RRF 融合排序，先应用明确条件再交由设备端模型精排。重排可以拒绝低相关候选。整个处理链路都在本机完成；关闭功能、设备不支持、苹果智能未开启、模型未就绪或处理失败时，保留普通关键词搜索。

筛选支持：

- 来源应用筛选。
- Handoff 筛选。
- 类型筛选：Text、Image、File、RTF、HTML 等。
- 时间筛选：全部、今天、昨天、本周、上周、最近 30 天。
- 备注筛选：全部、有备注、无备注。
- All / Favorites 标签切换。

面板关闭或重新打开时会清空临时搜索和筛选状态。

## 卡片操作

右键卡片会打开系统风格菜单。根据内容类型和文件存在性，菜单项会自动启用或禁用：

- 收藏 / 取消收藏：多选且右键落在选中集合内时整批切换；否则只动本卡。
- 备注：任何卡片都可添加场景备注，用来临时记录当时复制内容的用途或上下文。
- 复制：多选且落在选中集合内时合并为多行文本；否则写回本卡原内容。
- 打开：链接用默认浏览器打开，文件用默认应用打开，多链接或多文件会逐个打开。
- 打开方式：对可打开内容展示系统可用应用，并支持手动选择其他应用。
- 在 Finder 中显示：仅文件类内容可用。
- 预览：使用 Quick Look 风格预览；文本、RTF、HTML、链接会生成临时预览内容。
- 分享：调用系统分享服务。
- 删除：多选且落在选中集合内时整批删除；否则只删本卡。收藏不豁免用户删除。不主动清空系统剪贴板。

工具栏快捷操作与键盘 Delete 也提供多选粘贴 / 复制 / 删除，行为与右键一致（均可删除收藏）。开启苹果智能后，多选工具栏还提供智能处理入口。键盘 / 工具栏删除后若历史为空，会同步清空系统剪贴板。

### 智能操作

“苹果智能”总开关开启后，单条 Text、RTF、HTML 或图片记录的右键菜单启用“智能操作…”入口；关闭时入口保持禁用。文本入口直接展示原始内容，原文区使用稳定的紧凑视口，长内容可在区内滚动，不会因处理阶段切换而改变高度；图片入口先展示原图，不自动执行分析。文本的五个操作和图片最多三个操作都在窗口底部以等宽横向托盘排列，操作图标使用品牌暖棕加深色背景与白色图形，处理状态、草稿和结果显示在操作托盘上方；主操作按钮沿用相同的高对比配色。

“改写内容”会把最多 8000 个字符的原文交给设备端 Foundation Models，并明确要求在不改变事实和含义的前提下改写得清晰、自然、简洁；结果只生成文本草稿，仍需用户检查后复制。自定义指令输入框按 Return 直接执行，按 Shift + Return 插入换行。图片文字提取在用户选择对应动作后才运行 Vision OCR；用户还可以识别二维码与条码；macOS 27 及以上且设备端模型支持视觉输入时，可以生成图片描述。OCR、条码和图片描述结果完整进入可编辑结果区，不使用行数截断；较长内容由面板滚动承载。模型只生成草稿，剪贴板正文和图片分析结果始终作为不可信数据，不执行其中的指令。文本结果可编辑后复制；日历事件可编辑标题、全天状态、起止时间、地点和备注，用户确认后才申请仅写日历权限并保存；邮件可编辑收件人、主题和正文，确认后只打开系统配置的邮件撰写服务，不自动发送。相对日期以记录的复制时间为解释基准。日历和邮件草稿超过可用高度时在中间内容区滚动，原文和底部操作托盘保持稳定。文件记录不启用入口。

多选 2～10 条受支持内容时，工具栏显示智能处理按钮。批量面板顶部始终保留原始内容预览，来源编号可以横向滚动和切换；文本按需从数据库读取全文并在紧凑的固定高度区域滚动，图片读取缓存原图并缩放显示，处理完成后仍可在结果上方切换来源进行对照。初始选择阶段以三列网格展示操作及说明；选定操作后收为可横向滚动的单行紧凑操作条，并高亮当前操作，把垂直空间留给处理中状态、草稿和结果。纯文本选择提供综合总结、比较异同、合并重写、提取日程、拟定邮件和自定义操作；日程按来源分别生成候选，每条都要单独确认后才写入。纯图片选择提供批量文字提取、二维码与条码识别，并在 macOS 27 视觉模型可用时提供逐张描述。图文混选只提供综合总结、提取全部文字和自定义操作；模型操作会先按需执行 OCR，并在结果中保留 `[编号]` 来源。批量模型输入按卡片公平截取，总正文限制在 3200 个字符；处理串行执行，取消、切换操作或关闭窗口会停止未完成任务。包含文件或超过 10 条时，入口保持禁用并说明原因。

## 拖拽

卡片支持拖拽到其他应用。

单张拖拽：

- 链接优先暴露 URL，同时注册纯文本。
- 图片优先使用原图文件路径。
- 文件使用文件 URL。
- 文本、RTF、HTML 使用文本内容。

多选拖拽：

- 使用单个纯文本拖拽项，避免额外的 AppKit 事件覆盖层干扰 `Command` / `Shift` 点选。
- 文本、RTF、HTML 和文件路径会按卡片顺序合并为多行。
- 多选不额外暴露 URL 或文件 URL flavor；批量文件投递建议使用工具栏的粘贴或复制。

拖拽开始时面板会临时隐藏并允许鼠标事件穿透，避免 overlay 阻挡目标应用接收拖拽。

## 设置

设置窗口包含 General、Shortcut、Security、苹果智能、Version、About 六个页签。

### General

- 语言：跟随系统、简体中文、英文。
- Launch at Login：通过 `SMAppService` 管理开机启动。
- 声音：控制复制和粘贴提示音。
- 卡片点击模式：在单击直接粘贴与单击选择、再次点击粘贴之间切换；当前选项使用品牌暖棕加深色与白字标识。
- 删除确认：控制删除前是否显示确认提示。
- 历史保留：最大条数可选 100、500、1000、2000、5000；保留周期可选永不、7 天、30 天、90 天、1 年。
- 清空全部记录：删除全部历史记录并清空系统剪贴板。
- 侧边托盘：左右停靠固定使用紧凑历史列表，底部托盘继续使用横向卡片。

### 苹果智能

- 苹果智能：页面标题旁显示设备端模型的全局可用状态。总开关默认关闭，仅在模型可用时允许开启；开启后同时启用智能找回和单卡片智能操作，语义索引状态才会显示，重建入口才可用；关闭后停止模型分析、停用智能找回并禁用智能操作和索引交互，已有派生索引留在本机但不参与搜索。
- 重建语义索引：仅用于索引长期卡住、搜索结果明显过期，或系统升级后持续异常；日常无需操作。重建只清除并重新生成派生索引，不会删除剪贴板历史。

### Shortcut

用于录制全局面板快捷键。录制开始时会临时注销旧快捷键，保存或取消后重新注册。

### Security

- Accessibility 权限状态。
- 链接预览网络访问开关。
- 排除应用列表：识别到的来源应用在排除列表中时，复制内容不会写入 Pastry 历史（无来源标记的后台写入不能保证正确识别）；设置页支持添加和移除应用，列表超过四项后在区块内滚动，添加入口保持可见。
- 开发诊断记录：控制本地运行日志、性能样本和功能使用计数。

### Version

显示当前版本、更新状态和近期版本说明，并提供检查、下载和安装更新入口。

### About

显示应用信息、作者、版权、源码地址和许可说明。

## 隐私与安全

Pastry 的历史数据默认保存在本机应用数据目录。

当前安全策略包括：

- 数据库使用 SQLite + FTS5，数据只保存在本机。
- 新安装使用明文 SQLite，不创建数据库密钥；仓库内的兼容引擎用于 FTS5 和旧库迁移。
- 检测到旧版加密数据库及相邻 `.key` 时，会一次性转换为明文 SQLite；转换成功后删除旧密钥文件，失败时保留原库和密钥。
- 识别 `org.nspasteboard.ConcealedType`、`org.nspasteboard.TransientType`、`org.nspasteboard.AutoGeneratedType` 时跳过记录，分别避免保存敏感、临时中转和自动生成内容；不修改系统剪贴板。
- 支持按识别到的 bundle id 排除指定应用。来源字段显式为空时保持未知；缺失时仍按前台应用推测，无法保证识别后台截图或语音输入法。来源、类型和内容读取前后会核对变化编号，不一致时丢弃本次结果，避免错配后入库。
- 链接预览网络访问默认关闭，需要用户在 Security 中开启。
- 智能找回使用系统提供的设备端 Foundation Models 和 `NaturalLanguage`。为建立本地语义索引，设备端模型会处理受长度限制的历史正文、标题和备注；搜索重排只处理最多 36 条候选摘要。正文、摘要、标签和向量均留在本机，诊断日志不记录这些内容或搜索词。
- 智能操作按用户请求使用系统 Vision 执行单张或多张图片的文字、二维码和条码识别；macOS 27 及以上可在模型支持视觉能力时把原图作为设备端 Foundation Models 附件生成描述。识别内容、图片附件和模型输入输出均不写入诊断日志。自由指令只能生成文本，不能直接调用系统能力；单卡和多选的日历写入、邮件草稿均经过独立的可编辑确认步骤。
- 远程资源只允许 https，并阻止 localhost、`.local`、私有网段、链路本地地址和组播地址。
- 链接预览限制 HTML 响应大小为 2 MB，图片响应大小为 5 MB。

Accessibility 权限仅用于跨进程粘贴模拟，并在用户首次粘贴时请求。剪贴板记录、来源识别、全局快捷键和面板内滚动不依赖 Accessibility 或 Input Monitoring 权限。

## 数据与保留策略

剪贴板记录存储在 `clips.db` 中，核心字段包括内容、类型、来源应用、时间戳、收藏状态、展示计数、Handoff 标记、原始格式数据、链接标题和去重 key。

保存逻辑：

- 新内容写入数据库后会刷新面板列表、统计和可筛选应用列表。
- 相同 dedup key 的历史记录会被删除并以新时间戳重新插入，相当于置顶最新来源。
- 未找到历史记录、但同一去重 key 在 5 秒内连续出现时，视为快速重复并跳过；已有记录则走重新插入并置顶的路径。
- 面板内存列表默认加载最近 1000 条（跟随历史保留设置的条数上限），数据库可按该策略保存更多。
- 数据库触发器有 50,000 条的兜底上限，防止异常增长。
- 保留策略会跳过收藏记录，避免收藏内容被自动清理。
- 文件与图片路径每天在本机检查一次；非收藏记录的全部路径当前都不可访问时自动删除，仍有可用文件的多文件记录继续保留。未挂载外置卷中的非收藏路径也视为不可访问。

图片内容由 `ImageCacheManager` 管理缩略图和原图映射。文件类卡片只保存路径。

## 更新

菜单栏包含「检查更新」入口。自动检查会跳过开发构建；用户手动点击检查时仍会请求远端版本信息，方便验证更新链路。

## 验收场景

可以用以下场景验证当前产品行为：

1. 复制普通文本、链接、图片、文件和 HTML 富文本，确认面板生成对应卡片。
2. 用 `Command + Shift + V` 打开面板，确认 All/Favorites、搜索、筛选和设置入口可用。
3. 搜索内容和来源应用名，确认结果能命中。
4. 在设置的“苹果智能”页确认设备端模型状态显示在标题旁；开启总开关后，输入自然语言描述并点击智能找回，确认模型解析出的时间、来源和类型条件能筛出记录。关闭总开关后，确认语义索引状态隐藏、重建入口禁用、智能找回隐藏、卡片“智能操作…”禁用且普通关键词搜索仍可继续使用。
5. 开启苹果智能后，对单条文本右键选择“智能操作…”，确认原文区高度稳定且长内容可滚动、五个操作在窗口底部等宽横排、主按钮为品牌暖棕加深色与白字；分别验证总结、改写和自定义指令会显示对应的处理状态并在上方生成可编辑结果，自定义指令按 Return 执行、按 Shift + Return 换行；确认较长的日历和邮件草稿可在中间内容区滚动，字段与确认按钮不会被底部托盘挤出。对单张图片确认原图和结果位于上方、最多三个操作在底部等宽横排，并分别验证提取文字和识别二维码或条码按需执行、显示对应的处理状态且完整结果可编辑复制；在支持视觉输入的 macOS 27 设备上验证图片描述。验证日历草稿只在确认后请求权限并写入，邮件草稿只打开系统配置的邮件撰写服务而不发送。
6. 分别多选纯文本、纯图片和图文混合卡片，确认工具栏智能处理按钮打开对应的动态操作网格；逐个切换顶部来源编号，确认文本全文和图片原图可在紧凑的固定高度预览区滚动或缩放显示，生成结果后原始内容仍保留在上方用于对照。选择任一操作后，确认底部三列网格收为高亮当前操作的横向单行操作条，结果和草稿获得更大的垂直空间，仍可从操作条切换其他操作。验证纯文本的总结、比较、合并重写、日程、邮件和自定义，纯图片的批量 OCR、条码识别和可用时的逐张描述，以及混选的总结、提取全部文字和自定义。确认结果保留来源编号，多个日程逐条确认，包含文件或超过 10 条时入口禁用。
7. 收藏卡片后用键盘 Delete / 工具栏 / 右键删除，确认收藏也会被删掉；设置页清空全部同样清空收藏。
8. 对链接、文件、图片、文本分别右键，确认菜单项启用状态符合内容类型；多选后右键选中集合内任意一张，确认收藏/复制/删除作用于全部选中项。
9. 多选几张卡片后用工具栏或右键复制、粘贴和拖拽，确认文本与文件路径按多行纯文本合并，图片不参与多选载荷。
10. 关闭链接预览网络访问时复制链接，确认不会主动抓取远程预览；开启后确认安全策略允许的 https 链接可加载预览。
11. 将某个应用加入排除列表后，在该应用中复制内容，确认不会新增历史。
12. 调整历史保留数量或时间后，确认非收藏旧记录会被清理，收藏记录仍保留。
13. 删除一个未收藏文件的原路径并等待或触发每日维护，确认对应记录被清理；未挂载外置卷中的非收藏记录也会被清理，多文件记录仍有文件存在或记录已收藏时应保留。
14. 清空全部记录后，确认历史列表和系统剪贴板均被清空。
